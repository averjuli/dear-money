# Dear Money: экраны и дизайн

Макеты экранов лежат в `design/` (`*.dc.html`). Это файлы редактора дизайна: из них берём структуру, тексты и стили, но не код целиком. Цифры в макетах взяты из моей таблицы и служат примером.

Логика за экранами описана в `openspec/specs/`. Здесь только то, что видно на экране.

## Экраны
Образцы разметки лежат в `design/`. Размер артборда 390 px по ширине. Навигация: нижняя панель из двух вкладок («Конверты», «Траты») и отдельная круглая кнопка «+» справа от панели на обоих главных экранах.

### 1. Главная: конверты (`Main.dc.html`)
- Шапка: логотип `dear money` (Unbounded, акцентный цвет), справа текущий месяц.
- Акцентная карточка: «Всего в конвертах» крупно (в макете 230 350 ₽ без кошелька «Запасные»; с ним по демо-данным 233 950 ₽, считать по всем кошелькам); чипы «Откладывать X ₽ в месяц» и «N конвертов в минусе».
- Карточка «Пришли деньги? Разложу зарплату по конвертам» → экран 3.
- Карточка «На жизнь осталось X ₽» с полоской израсходованного; если какая-то категория превысила лимит, строка предупреждения «Транспорт превышен на 2 230 ₽» → экран 4.
- Заголовок «Кошельки» и ссылка «Настроить».
- Список кошельков: название, «N конвертов» или «N конвертов · K в минусе» (цвет предупреждения), сумма. Нажатие → экран 5 для этого кошелька. Порядок кошельков в макете по убыванию суммы; в данных у кошельков есть свой порядок (открытый вопрос 6 в `01-продуктовая-идея.md`).
- Нижняя навигация, «Конверты» активна; кнопка «+» → экран 2.

### 2. Новая трата (`Trata.dc.html`)
- Заголовок, крестик закрытия → назад.
- Сумма крупно, числовая клавиатура (`inputmode="decimal"`), автофокус.
- «Откуда списать»: переключатель «Повседневное» / «Из конверта».
  - «Из конверта»: недавние конверты кнопками-чипами, последняя «Все конверты» открывает полный список по кошелькам.
  - «Повседневное»: те же чипы, но с категориями повседневных трат.
- Подсказка-последствие под выбором (только для конверта): «В „Маникюре“ станет 8 700 ₽, хватит ещё на 2 раза». Если уходит в минус: «В „Бровях“ станет −350 ₽» в цвете предупреждения.
- Дата (по умолчанию «Сегодня»), заметка (необязательно).
- «Сохранить» → назад, на экран, откуда пришли.
- Позже: редактирование и удаление траты по нажатию в списке трат.

### 3. Пришли деньги (`Dohod.dc.html`)
- Назад → экран 1.
- «Сколько пришло»: поле суммы; чипы «Зарплата», «Аванс», «Другое».
- «Как я разложу»: полоса из двух частей (в конверты / на повседневные траты).
- Список: «В конверты» с суммой; под ним взносы по каждому кошельку по убыванию; «На повседневные траты» с подписью «всё, что осталось после конвертов».
- Карточка излишка: «Излишек 7 450 ₽ в Self-care. Четыре конверта уже полные, их взносы уйдут в „Косметологию“ по приоритету». Если излишков несколько, по строке на кошелёк.
- «Разложить» применяет раскладку (`openspec/specs/income-allocation`) → экран 1.
- Нужно добавить, в макете нет: поле «Следующие деньги придут» (дата), по нему считается «≈ N ₽ в день» на экране 4. Если доход меньше суммы взносов, показать предупреждение (открытый вопрос 2 в `01-продуктовая-идея.md`).

### 4. Повседневные траты (`Traty.dc.html`)
- Заголовок «Повседневные траты».
- Акцентная карточка: «Осталось на жизнь до <дата следующего дохода>» крупно; полоска; «потрачено X из Y ₽»; «≈ N ₽ в день».
- Пояснение: «Это всё, что осталось от зарплаты после конвертов. Траты из конвертов сюда не входят».
- «По категориям» с подписью «лимит необязателен». С лимитом: «потрачено из лимита», полоска, «осталось X» или «лимит превышен на X» (цвет предупреждения). Без лимита: название и сумма. Нажатие → экран 7.
- «Последние»: категория, когда, сумма.
- Нижняя навигация, «Траты» активна; кнопка «+».
- Нужно добавить: «Добавить категорию».

### 5. Кошелёк: приоритеты и излишек (`Koshelek.dc.html`)
- Назад → экран 1. Подзаголовок «Кошелёк», название.
- Две плитки: «Откладывать в месяц» (сумма взносов кошелька) и «Сейчас в кошельке» (сумма остатков).
- Акцентная карточка излишка, если он есть: «Излишек в этом месяце: X ₽» и куда он уйдёт.
- «Конверты по приоритету» с подсказкой «перетащите, чтобы изменить». Строка: номер приоритета, название, статус, взнос «X ₽/мес», ручка перетаскивания.
  - Статусы: «накоплено на N раз» (акцент) для полных; «копится · на N раз» для остальных; «минус X ₽» (предупреждение).
  - Строка, которая получит излишек, подсвечена фоном предупреждения с подписью «получит излишек».
- Нажатие на строку → экран 6. «Добавить конверт» внизу.

### 6. Настройка конверта (`Kategoriya.dc.html`)
- Назад → экран 5. Подзаголовок «<кошелёк> · конверт», название.
- «Сколько стоит один раз» (₽).
- «Как часто»: «раз в [N]» + переключатель «недели / месяца / года».
- Акцентная карточка «Откладывать в месяц» крупно и формула словами: «Считается само: 2 800 ₽ ÷ 2 месяца».
- «На сколько раз копить»: кнопки − и +, число; полоска заполнения; «Потолок X ₽» и «накоплено X ₽, полная» или «до потолка X ₽».
- «Приоритет в кошельке: k из N» → экран 5.
- Пояснение «Что будет с излишком» для полного конверта.
- «Сохранить». Нужно добавить: «Начальный остаток» (для переноса из таблицы), «Переименовать», «Удалить конверт», «Задать взнос вручную» (`openspec/specs/envelopes`).

### 7. Настройка категории трат (`Limit.dc.html`)
- Назад → экран 4. Подзаголовок «Повседневные траты · категория».
- Название; «Лимит на месяц» (можно оставить пустым).
- Сводка за период: «Потрачено X ₽, на Y больше лимита».
- «Последние траты» в этой категории.
- «Сохранить», «Удалить категорию».

### 8. Экраны, которых нет в макете
- **Вход:** логин и пароль. Простой экран в том же стиле.
- **Все конверты:** полный список по кошелькам для выбора на экране 2.
- **Создание кошелька и конверта:** в макете есть только кнопки «Добавить», сами формы повторяют экран 6.
- **Как установить на iPhone:** три шага картинкой: Safari → Поделиться → На экран «Домой».
- **История доходов** и правка распределения задним числом: позже.
- **Первый запуск для новых пользователей:** позже, когда появятся другие люди.

## Десктоп

Макеты `design/DMain.dc.html`, `DKoshelek.dc.html`, `DTraty.dc.html`, `DDohod.dc.html`. Те же данные и логика, что на телефоне, другая раскладка:

- Слева боковое меню: логотип, «Конверты», «Траты», «Пришли деньги», внизу «Настройки». На узком экране меню уходит наверх, контент под ним.
- **Конверты:** три карточки сверху (всего в конвертах, на жизнь осталось, откладывать в месяц), ниже сетка карточек кошельков с главными конвертами внутри, справа колонка «Пришли деньги?» и повседневные траты.
- **Кошелёк:** таблица конвертов по приоритету (статус, заполненность, остаток, потолок, взнос, перетаскивание), справа панель настройки выбранного конверта вместо отдельного экрана.
- **Траты:** карточка «осталось на жизнь», категории с лимитами и таблица последних трат; справа форма «Новая трата» всегда открыта.
- **Пришли деньги:** слева форма (сумма, вид дохода, дата следующих денег), справа предпросмотр раскладки, взносы по кошелькам и излишек.
- Кнопка «Внести трату» в шапке главной ведёт на «Траты», где форма уже открыта.
- Ширина контента не больше 1180 px; всё перестраивается в одну колонку на узком окне.

## Визуальный стиль
Взят из макета. Тёмной темы в макете нет: пока не делаем, но цвета держим токенами, чтобы добавить потом.

| Токен | Значение | Где |
|---|---|---|
| `bg` | `#EDF1EE` | фон экрана |
| `surface` | `#FFFFFF` | карточки |
| `surface-sunken` | `#F4F7F5` | поля ввода, вложенные блоки |
| `ink` | `#14211B` | основной текст |
| `ink-muted` | `#55635C` | вторичный текст |
| `accent` | `#1B6B4D` | кнопки, акцентные карточки, полоски |
| `accent-strong` | `#14523B` | чипы на акцентной карточке, нажатое |
| `accent-soft` | `#DCEBE3` | выбранные чипы, подсказки, активная вкладка |
| `warn` | `#A34D14` | минус, превышение лимита |
| `warn-strong` | `#8A4315` | текст на `warn-soft` |
| `warn-soft` | `#FBEADD` | фон предупреждений |
| `warn-bar` | `#C46A2B` | полоска превышения, доля повседневных |
| `line` | `#E3E9E5` | разделители, фон полосок |
| `dash` | `#9DB5A9` | пунктир кнопок «Добавить…» |

**Шрифты** (Google Fonts): Golos Text 400/500/600/700 для текста; Unbounded 500/600 для логотипа, заголовков экранов и крупных сумм.

**Размеры**
- Отступы экрана: 56 px сверху (с учётом safe-area), 20 px по бокам, 20–24 px снизу. Промежуток между блоками 14 px.
- Скругления: карточки 20 px, крупные карточки 24 px, кнопки и поля 14–16 px, чипы 999 px, кнопка «+» 20 px (60×60).
- Заголовок экрана 24–26 px Unbounded 600; крупная сумма 32–40 px Unbounded 600; текст 15–16 px; подписи 13–14 px.
- Полоска прогресса 8 px, скругление 4 px.
- Иконки: линейные SVG, толщина 2.2–2.6, без эмодзи.

**shadcn/ui.** Компоненты берём, но перекрашиваем токенами выше: никаких цветов и скруглений по умолчанию из shadcn, если они расходятся с макетом.

## Маскот Копи

Персонаж ещё рисуется, в интерфейс пока не добавляем. Наброски лежат в макете на листах «Копи». Направление: большая круглая голова, мягкое тело-капля, ручки-палочки, короткие ножки, держит большую монету; чёрный контур почти как скетч, розовый румянец.
