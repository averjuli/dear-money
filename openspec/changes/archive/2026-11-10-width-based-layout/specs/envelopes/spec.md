# Spec Delta

## REMOVED Requirements

### Requirement: Главные конверты кошелька
**Reason**: Карточки кошельков с главными конвертами внутри были только на десктопной главной. Десктопная раскладка уходит: на любой ширине окна главная показывает кошельки списком, как на телефоне, с суммой и числом конвертов.
**Migration**: Ничего делать не нужно: данные не меняются. Все конверты кошелька по приоритету видны на экране кошелька.
